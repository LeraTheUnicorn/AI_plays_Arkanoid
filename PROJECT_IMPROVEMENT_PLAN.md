## 🔄 Процесс работы

### Правила:
1. Делать коммит после завершения редактирования каждого файла
2. Выводить прогресс работы в реальном времени
3. Обновлять список выполненных задач в реальном времени
4. Останавливать работу и предупреждать пользователя при зацикливании
5. Проверять синтаксис и линтер после каждого изменения

### Шаблон коммита:
```
[Тип]: [Краткое описание] - [Детали]

Типы:
- Рефакторинг: изменения структуры кода
- Оптимизация: улучшение производительности
- Исправление: исправление ошибок
- Документация: обновление документации
- Тесты: добавление тестов
```
