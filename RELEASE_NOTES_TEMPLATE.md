### 🚀 Установка

```bash
# Клонирование репозитория
git clone https://github.com/LeraTheUnicorn/AI_plays_Arkanoid.git
cd AI_plays_Arkanoid

# Установка зависимостей (через Poetry)
poetry install

# Или через pip
pip install -r requirements.txt

# Запуск игры
python game/PyGameBall.py
```
