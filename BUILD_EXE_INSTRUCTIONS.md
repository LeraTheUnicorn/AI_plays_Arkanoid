# Инструкция по сборке EXE файла для игры Arkanoid

## Требования

1. **Python 3.11+** (уже установлен)
2. **PyInstaller** (будет установлен автоматически, если отсутствует)
3. Все зависимости проекта (установлены через Poetry)

## Быстрая сборка

Просто запустите скрипт:

```bash
build_exe.bat
```

Скрипт автоматически:
1. Проверит наличие PyInstaller
2. Установит PyInstaller при необходимости
3. Очистит предыдущие сборки
4. Создаст exe файл
5. Покажет результат

## Ручная сборка

Если хотите собрать вручную:

```bash
# 1. Установите PyInstaller (если еще не установлен)
python -m pip install pyinstaller

# 2. Запустите сборку
python -m PyInstaller arkanoid.spec --clean --noconfirm
```

## Результат

После успешной сборки exe файл будет находиться в:
```
dist\Arkanoid.exe
```

Вы можете запустить игру двойным кликом по этому файлу.

## Размер файла

Размер exe файла будет примерно 50-150 МБ (зависит от включенных зависимостей).

## Возможные проблемы и решения

### Проблема: "ModuleNotFoundError"

**Решение**: Добавьте недостающий модуль в список `hiddenimports` в файле `arkanoid.spec`

### Проблема: Ресурсы не загружаются

**Решение**: Убедитесь, что все ресурсы находятся в папке `resources/` и правильно указаны в `datas` секции spec файла

### Проблема: Игра не запускается

**Решение**: Запустите сборку с `console=True` в spec файле (временно), чтобы видеть ошибки:
```python
console=True,  # Вместо console=False
```

### Проблема: Антивирус блокирует exe

**Решение**: Это нормально для PyInstaller exe файлов. Добавьте в исключения антивируса или подпишите exe файл сертификатом.

## Настройка spec файла

### Изменить название exe файла

Отредактируйте `arkanoid.spec`:
```python
name='Arkanoid',  # Измените на желаемое имя
```

### Добавить иконку

1. Создайте файл иконки `icon.ico`
2. Поместите его в папку `resources/`
3. Отредактируйте `arkanoid.spec`:
```python
icon=str(project_root / 'resources' / 'icon.ico'),
```

### Показать консоль для отладки

Временно измените в `arkanoid.spec`:
```python
console=True,  # Показывать консоль (для отладки)
```

### Уменьшить размер exe

Используйте UPX компрессию (уже включена) или исключите ненужные модули:
```python
excludes=[
    'matplotlib',
    'tkinter',
    # добавьте другие ненужные модули
],
```

## Структура ресурсов

Убедитесь, что в папке `resources/` находятся:
- `FVCK_AI.mp3` - фоновая музыка
- `settings.json` - настройки игры
- `5000.png` - изображение (если используется)
- `images/` - папка с изображениями (если используется)

## Распространение exe

Вы можете распространять только файл `dist\Arkanoid.exe` - все зависимости уже включены в него.

**Важно**: Файл будет работать только на Windows с той же разрядностью (32/64 бит), на которой он был собран.
