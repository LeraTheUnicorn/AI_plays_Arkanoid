### ШАГ 3: Создание тега

#### Вариант A: Легковесный тег (lightweight tag)
```bash
git tag v2.3.161
git push origin v2.3.161
```

#### Вариант B: Аннотированный тег (рекомендуется)
```bash
git tag -a v2.3.161 -m "Release version 2.3.161"
git push origin v2.3.161
```

#### Вариант C: Создание тега на конкретном коммите
```bash
# Сначала посмотрите последние коммиты
git log --oneline -10

# Создайте тег на конкретном коммите
git tag -a v2.3.161 <commit-hash> -m "Release version 2.3.161"
git push origin v2.3.161
```

### ШАГ 5: Создание GitHub Release через веб-интерфейс

1. Перейдите на страницу репозитория:
   ```
   https://github.com/LeraTheUnicorn/AI_plays_Arkanoid
   ```

2. Перейдите в раздел "Releases":
   - Нажмите на ссылку "Releases" справа от кода
   - Или перейдите по прямой ссылке:
     ```
     https://github.com/LeraTheUnicorn/AI_plays_Arkanoid/releases
     ```

3. Нажмите "Draft a new release" или "Create a new release"

4. Заполните форму:
   - **Choose a tag**: Выберите созданный тег (v2.3.161) или создайте новый
   - **Target**: Выберите ветку (develop, main, или master)
   - **Release title**: `Release v2.3.161` или `v2.3.161`
   - **Description**: Вставьте подготовленные Release Notes

5. Опционально - добавьте артефакты:
   - Загрузите архив с исходным кодом
   - Загрузите исполняемые файлы (если есть)
   - Загрузите документацию

6. Выберите тип релиза:
   - **Latest release** - если это последний стабильный релиз
   - **Pre-release** - если это бета/альфа версия

7. Нажмите "Publish release"

### ШАГ 6: Создание GitHub Release через GitHub CLI (альтернатива)

Если у вас установлен GitHub CLI (`gh`):

```bash
# Проверка установки
gh --version

# Авторизация (если еще не выполнена)
gh auth login

# Создание релиза
gh release create v2.3.161 \
  --title "Release v2.3.161" \
  --notes-file RELEASE_NOTES.md \
  --target develop
```

Или интерактивный режим:
```bash
gh release create v2.3.161 --interactive
```
