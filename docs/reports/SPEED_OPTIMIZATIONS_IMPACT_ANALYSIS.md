#### ❌ Риск 1: Неточное предсказание на большом расстоянии

**Сценарий:**
- Мяч на y=100, скорость 8px/кадр
- Время до приземления: `(540-100)/8 = 55 кадров` (917ms)
- За это время мяч может:
  - Отскочить от **множества блоков**
  - Изменить траекторию **непредсказуемо**
  - Попасть в блок, который изменит направление

**Вероятность ошибки:**
- При скорости 8: **Высокая** (55 кадров = много времени для изменений)
- При скорости 30: **Низкая** (14.7 кадров = мало времени для изменений)

#### ❌ Риск 2: Платформа начинает движение слишком рано

**Сценарий:**
- Мяч на y=100, предсказана позиция x=400
- Платформа начинает движение к x=400
- Но мяч отскакивает от блока и меняет траекторию
- Платформа уже движется в неправильном направлении

**Вероятность ошибки:**
- При скорости 8: **Средняя** (есть время для коррекции)
- При скорости 30: **Низкая** (нет времени для коррекции)

**Проблемы для низких скоростей:**

#### ❌ Риск 1: Пропуск отскоков от блоков

**Сценарий (низкая скорость 8):**
- Мяч движется медленно (8px/кадр)
- Время до приземления: 55 кадров
- За это время мяч может отскочить от **5-10 блоков**

- Результат: **Неправильная позиция приземления**

**Вероятность ошибки:**
- При скорости 8: **Очень высокая** (много времени = много отскоков)
- При скорости 30: **Низкая** (мало времени = мало отскоков)

#### ❌ Риск 2: Потеря точности прицеливания

**Сценарий:**
- Осталось 1-5 блоков
- Нужна **точная** позиция для прицеливания
- Упрощенный расчет дает **приблизительную** позицию
- Результат: **Пропуск блока** или **потеря мяча**

**Вероятность ошибки:**
- При малом количестве блоков: **Высокая**
- При большом количестве блоков: **Низкая**

def predict_paddle_intersection(
    self, game_state: GameState, paddle_y: float
) -> Optional[Point]:
    """
    Предсказывает точку пересечения с адаптивным расчетом.
    """
    ball_speed = abs(game_state.ball_velocity.y)
    bricks_count = len(game_state.remaining_bricks) if game_state.remaining_bricks else 50
    ball_y = game_state.ball_position.y
    
    # Условия для упрощенного расчета:
    use_simple = (
        ball_speed >= 25 and           # Высокая скорость
        bricks_count >= 10 and         # Много блоков (меньше важность точности)
        ball_y < 300                   # Мяч далеко (есть время на коррекцию)
    )
    
    if use_simple:
        return self._simple_intersection_calculation(game_state, paddle_y)
    else:
        # Полная симуляция для точности
        return self._full_trajectory_simulation(game_state, paddle_y)

def _simple_intersection_calculation(
    self, game_state: GameState, paddle_y: float
) -> Optional[Point]:
    """
    Упрощенный расчет без проверки всех блоков.
    Учитывает только отскоки от стен.
    """
    ball_x = game_state.ball_position.x
    ball_y = game_state.ball_position.y
    vel_x = game_state.ball_velocity.x
    vel_y = game_state.ball_velocity.y
    
    if abs(vel_y) < 0.1:
        return None
    
    time_to_paddle = (paddle_y - ball_y) / vel_y
    if time_to_paddle <= 0:
        return None
    
    # Упрощенный расчет только с отскоками от стен
    # (без проверки блоков для скорости)
    predicted_x = ball_x + vel_x * time_to_paddle
    
    # Учитываем отскоки от стен
    ball_radius = 8
    min_x = ball_radius
    max_x = self.screen_width - ball_radius
    
    # Простой расчет отскоков (без итераций)
    while predicted_x < min_x or predicted_x > max_x:
        if predicted_x < min_x:
            predicted_x = 2 * min_x - predicted_x
            vel_x = abs(vel_x)
        elif predicted_x > max_x:
            predicted_x = 2 * max_x - predicted_x
            vel_x = -abs(vel_x)
    
    return Point(int(predicted_x), int(paddle_y))
```

**Преимущества:**
- ✅ Низкие скорости: всегда полная симуляция
- ✅ Высокие скорости + много блоков: упрощенный расчет
- ✅ Малые скорости + мало блоков: полная симуляция для точности

def should_recalculate_target(self, ball_y: float, last_prediction_y: float) -> bool:
    """
    Определяет, нужно ли пересчитать целевую позицию.
    
    Args:
        ball_y: Текущая Y-координата мяча
        last_prediction_y: Y-координата мяча при последнем предсказании
        
    Returns:
        True, если нужно пересчитать
    """
    # Пересчитываем, если мяч прошел значительное расстояние
    distance_traveled = abs(ball_y - last_prediction_y)
    
    if distance_traveled > 50:  # Мяч прошел 50px
        return True
    
    # Пересчитываем каждые 10 кадров для низких скоростей
    if self.ball_speed < 15 and self.frame_counter % 10 == 0:
        return True
    
    return False
```

**Преимущества:**
- ✅ Корректирует предсказание по мере приближения мяча
- ✅ Учитывает изменения траектории
- ✅ Снижает риск ошибки на низких скоростях
