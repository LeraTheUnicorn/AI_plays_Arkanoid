# Реализация асинхронного логирования

## Дата: 2025-12-15

---

## ✅ РЕАЛИЗОВАНО: Асинхронное логирование в отдельном потоке

### Проблема:
- Логирование было синхронным и блокировало основной поток игры
- Ротация файлов логов вызывала фризы на ~1 секунду
- При высокой частоте логирования это создавало заметные задержки

### Решение:
- Реализовано асинхронное логирование с использованием `QueueHandler` и `QueueListener`
- Логи записываются в очередь и обрабатываются в отдельном потоке
- Основной поток игры не блокируется при записи логов

---

## 📁 НОВЫЕ ФАЙЛЫ

### `ai/async_logging_handler.py`
- Класс `AsyncLoggingSetup` для настройки асинхронного логирования
- Использует `QueueHandler` для отправки логов в очередь
- Использует `QueueListener` для обработки логов в отдельном потоке
- Глобальные функции `get_async_logging_setup()` и `stop_async_logging()`

---

## 🔧 ИЗМЕНЕННЫЕ ФАЙЛЫ

### `ai/ai_player_init.py`
- Интегрировано асинхронное логирование в `_setup_logging()`
- `file_handler` теперь используется через `QueueListener`
- `QueueHandler` добавляется к логгеру вместо прямого `file_handler`

---

## 🎯 КАК ЭТО РАБОТАЕТ

### До (синхронное логирование):
```
Основной поток: logger.debug() → FileHandler.emit() → запись в файл (блокирует)
```

### После (асинхронное логирование):
```
Основной поток: logger.debug() → QueueHandler.emit() → добавление в очередь (не блокирует)
Отдельный поток: QueueListener → извлечение из очереди → FileHandler.emit() → запись в файл
```

---

## ✅ ПРЕИМУЩЕСТВА

1. **Не блокирует основной поток:**
   - Запись в очередь происходит мгновенно
   - Основной поток игры не останавливается

2. **Ротация файлов не вызывает фризов:**
   - Ротация происходит в отдельном потоке
   - Игровой цикл продолжает работать

3. **Высокая производительность:**
   - Очередь обрабатывается асинхронно
   - Множественные логи не блокируют игру

---

## 📊 ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ

После реализации:
- **Устранение фризов:** Логирование больше не блокирует игровой цикл
- **Плавная игра:** Даже при высокой частоте логирования игра работает плавно
- **Стабильность:** Ротация файлов не вызывает задержек

---

## 🔍 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### QueueHandler:
- Отправляет логи в очередь
- Не блокирует основной поток
- Работает мгновенно

### QueueListener:
- Обрабатывает логи в отдельном потоке
- Использует `file_handler` для записи в файл
- Автоматически запускается при вызове `start()`

### Очередь:
- Неограниченная очередь (`queue.Queue(-1)`)
- Потокобезопасная
- Автоматически обрабатывается `QueueListener`

---

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Остановка логирования:**
   - При завершении программы нужно вызвать `stop_async_logging()`
   - Это гарантирует, что все логи будут записаны

2. **Единый экземпляр:**
   - Используется глобальный экземпляр `AsyncLoggingSetup`
   - Все логгеры используют одну очередь и один listener

3. **Совместимость:**
   - Работает с любыми `Handler` (включая `RotatingLinesFileHandler`)
   - Не требует изменений в коде, который использует логирование

---

## ✅ ГОТОВНОСТЬ К ТЕСТИРОВАНИЮ

Асинхронное логирование готово к использованию. Ожидается:
- Устранение фризов из-за логирования
- Плавная работа игры даже при высокой частоте логирования
- Стабильность при ротации файлов логов
