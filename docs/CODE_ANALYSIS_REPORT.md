### 1. Модули `ai/core/` - АЛЬТЕРНАТИВНАЯ АРХИТЕКТУРА (НЕ ИСПОЛЬЗУЕТСЯ)

**Статус:** ⚠️ **АЛЬТЕРНАТИВНАЯ РЕАЛИЗАЦИЯ, НЕ ИСПОЛЬЗУЕТСЯ В ОСНОВНОМ КОДЕ**

- `ai/core/ai_coordinator.py` - **395 строк** ⚠️
- `ai/core/decision_maker.py` - **1,349 строк** ⚠️
- `ai/core/movement_engine.py` - **1,617 строк** ⚠️

**Итого:** **3,361 строка неиспользуемого кода**

**Доказательство:**
- Нигде в коде нет создания экземпляров `AICoordinator`, `DecisionMaker`, `MovementEngine`

**Важно:** Это может быть незавершенный рефакторинг или альтернативная реализация для будущего использования.

**Рекомендация:** 
- Если это незавершенный рефакторинг → УДАЛИТЬ
- Если планируется использовать в будущем → ОСТАВИТЬ, но переместить в `ai/experimental/` или `ai/alternative/`
